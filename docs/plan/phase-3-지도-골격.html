Phase 3 — iOS 지도 골격

여기서 처음 Xcode를 연다. 실기기 지도 위에 서울 데이터가 레벨별로 찍히면 성공

선행: Phase 2 적재 완료 · 예상 3~4일 · 다음: Phase 4 연대기 상세

✅ 완료 판정 — 실기기(iPhone)에서 직접 조작해 확인한다

  1. 앱을 실행하면 서울 전체 뷰에서 구 단위 마커(평균 교체 수)가 보인다.
  2. 핀치 줌인하면 구 → 동 → 개별 자리 순으로 마커가 바뀐다.
  3. 강남역 일대까지 줌인하면 개별 자리 마커가 교체 수에 따라 다른 색으로 찍힌다.
  4. 지도를 빠르게 드래그해도 앱이 버벅이거나 요청이 폭주하지 않는다 (디바운스 확인).
  5. 비행기 모드에서 실행하면 빈 화면이 아니라 안내 문구가 뜬다.

1. 프로젝트 생성 — XcodeGen

TeslaSync와 같은 방식: project.yml이 소스이고 .xcodeproj는 커밋하지 않는다.

# ios/project.yml
name: Ijari
options:
  bundleIdPrefix: com.jkpark
  deploymentTarget:
    iOS: "17.0"
packages:
  Supabase:
    url: https://github.com/supabase/supabase-swift
    from: 2.0.0
targets:
  Ijari:
    type: application
    platform: iOS
    sources: [Ijari]
    dependencies:
      - package: Supabase
        product: Supabase
    settings:
      base:
        DEVELOPMENT_TEAM: WDNVP9B8A9        # 무료 팀. Phase 6에서 유료 팀으로 교체
        PRODUCT_BUNDLE_IDENTIFIER: com.jkpark.ijari
        INFOPLIST_KEY_NSLocationWhenInUseUsageDescription: 현재 위치 주변의 자리를 지도에 보여주기 위해 사용합니다.

cd ios && xcodegen generate && open Ijari.xcodeproj

무료 팀 프로비저닝은 7일마다 만료된다 — 실기기에서 앱이 갑자기 안 열리면 재빌드가 먼저다. 또 시뮬레이터에서도 지도·네트워크는 다 돌아가므로 이 phase는 시뮬레이터로 개발하고 실기기는 완료 판정 때 확인하면 된다 (TeslaSync와 달리 실기기 전용 제약이 없다).

3. 줌 사다리 — MapLevel

enum MapLevel: Equatable {
    case sido, sigungu, dong, places

    init(span: MKCoordinateSpan) {
        switch span.longitudeDelta {
        case ..<0.08:  self = .places
        case ..<0.35:  self = .dong
        case ..<1.5:   self = .sigungu
        default:       self = .sido
        }
    }
}

경계값(0.08 / 0.35 / 1.5)은 plan-overview의 D2에서 정한 잠정치다. 실기기에서 손맛을 보고 조정하되, 레벨이 바뀌는 순간 마커가 전부 갈리는 시각적 점프는 정상이다 — MVP에서 부드러운 전환 애니메이션은 범위 밖.

4. 데이터 로딩 — 디바운스와 취소

// MapScreen.swift 핵심 로직
@State private var loadTask: Task<Void, Never>?

func onCameraChange(_ context: MapCameraUpdateContext) {
    loadTask?.cancel()                       // 이전 요청 취소
    loadTask = Task {
        try? await Task.sleep(for: .seconds(0.3))   // 디바운스
        guard !Task.isCancelled else { return }
        let region = context.region
        let level = MapLevel(span: region.span)
        do {
            switch level {
            case .places:
                markers = .places(try await client.mapPlaces(bbox: region.bbox))
            default:
                markers = .regions(try await client.mapRegions(level: level, bbox: region.bbox))
            }
        } catch is CancellationError {
        } catch {
            loadState = .failed(error)
        }
    }
}
  • 드래그 중 카메라 이벤트는 초당 수십 번 온다 — 0.3초 디바운스 + 직전 Task 취소가 없으면 RPC가 폭주한다 (완료 판정 4번이 이걸 잡는다).
  • IjariClient는 bbox를 반올림한 키로 메모리 캐시(NSCache 또는 딕셔너리, 상한 ~50개 항목)를 둔다. D4 결정대로 디스크 캐시는 없다.
  • RPC 호출은 supabase-swift로: client.rpc("map_places", params: [...]).execute() → [Place] 디코딩. 컬럼명이 snake_case이므로 keyDecodingStrategy = .convertFromSnakeCase 또는 명시적 CodingKeys.

  • 마커 안에 교체 수 숫자를 흰색으로 표기 (색만으로 구분하지 않는다 — 접근성).
  • confidence == "low"(층 미상) → 불투명도 50%. "이 자리 정보는 층 구분이 없어 덜 정확함"의 시각 신호.
  • is_occupied == false(공실 후보) → 테두리 점선. MVP에서 지도 필터는 없고 표시만.

지역 마커

원형 배지: 큰 숫자 = 평균 교체 수(소수 1자리), 작은 글씨 = 지역명. 탭하면 그 지역으로 줌인(카메라 이동)만 한다 — 상세 화면은 자리 전용.

6. 오프라인·에러 UX (D4 온라인 전용의 대가)

  • 첫 로딩 실패(네트워크 없음) → 전면 안내: "인터넷 연결이 필요한 앱입니다" + 재시도 버튼.
  • 지도 조작 중 일시 실패 → 기존 마커를 지우지 않고 상단에 얇은 배너 + 자동 재시도 1회.
  • Supabase 무료 티어 pause 상태(개발 중 자주 겪는다)도 같은 경로로 떨어진다 — 에러 문구에 원인 추정을 넣지 말고 중립적으로.

7. 이 phase에서 하지 않는 것

  • 자리 탭 → 상세 바텀시트: Phase 4. (이 phase에서 자리 마커 탭은 아무 동작 없어도 완료 가능.)
  • 현재 위치 버튼·위치 권한 요청: Phase 4에서 상세와 함께. (Info.plist 문구만 미리 넣어둔다.)
  • 검색·필터·클러스터링: MVP 범위 밖 (기획서 제외 목록).
